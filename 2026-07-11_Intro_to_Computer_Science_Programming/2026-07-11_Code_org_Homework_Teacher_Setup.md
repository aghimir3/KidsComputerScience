# Code.org Homework Teacher Setup

## Assignment

**Music Lab Remix Challenge**
**Student activity:** https://code.org/en-US/hour-of-code/music
**Points:** 100 points + 5 bonus points

## Before Sharing the Homework

1. Sign in to your Code.org teacher account.
2. Create or select the Kids Computer Science class section.
3. Open the section menu and choose **Section settings**.
4. In **Assign Curriculum**, open the **Hour of Code** tab.
5. Select **Music Lab: Jam Session** and save.
6. Copy the section's six-character code or joining link.
7. Replace the placeholders in `Homework_Teams_Post.txt`.
8. Show students how to sign in before they leave class.

Code.org supports one assigned course or unit per class section at a time.
Record any existing assignment before changing it. Existing student progress is
preserved when the assigned course changes.

Official help:
https://support.code.org/hc/en-us/articles/14961986498189-How-do-I-assign-an-Hour-of-Code-activity-to-my-class-section

## What Students Complete

- Finish the guided Music Lab levels.
- Use at least three sounds in the final remix.
- Add an AI-generated drum beat.
- Make at least two creative changes.
- Give the remix a school-appropriate title.
- Test the complete project.
- Submit the requested evidence in Microsoft Teams.

## Teacher Progress Check

Use the Code.org teacher dashboard to check student progress. Students must be
signed in for their work to be saved and connected to the class section.

## Sharing Safety

- Use first name and last initial or the class naming convention.
- Do not put personal addresses, phone numbers, or private information in titles.
- Check Code.org sharing permissions before asking students to submit a public link.
- A screenshot is acceptable when project sharing is unavailable.
