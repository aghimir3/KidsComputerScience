🎯 YOUR MISSION

Work in a group of 3 to create a short presentation reviewing EVERYTHING we've learned about AI since April!

Your team will build a PowerPoint (or Google Slides, Canva, etc.) and present it to the class (~3-4 minutes).

Your presentation must tell a story featuring an AI agent character that shows off the key concepts we learned.

📊 Points: 100 (+10 bonus)

👥 TEAM ROLES (1 per person)

🧠 AI Architect
   → Design the AI character: pick the LLM, write a system prompt using RTCF, choose a temperature, list the tools & memory

📝 Story Director
   → Write the story/skit: show the Think → Act → Observe loop in action, include a hallucination moment the user catches

🎨 Presenter/Designer
   → Build the slides and lead the presentation: include key vocabulary, make it visual, practice delivery

Every role touches on concepts from class — no one is left out!

⏱️ TIME BUDGET (90 minutes)

0-10 min   → Setup, read the brief, assign roles, brainstorm
10-60 min  → Build! (50 min — work together)
60-70 min  → Combine everything + practice
70-90 min  → Class presentations (~3-4 min each)
