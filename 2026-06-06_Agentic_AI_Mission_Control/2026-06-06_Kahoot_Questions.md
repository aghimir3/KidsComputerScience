## Question 1

**Q:** What is the main difference between vibe coding and agentic coding?
- A) Vibe coding uses computers, agentic coding does not
- B) Agentic coding includes goals, tools, testing, and supervision
- C) Vibe coding is always wrong
- D) Agentic coding means the human does nothing

**Correct:** B

---

## Question 2

**Q:** Why should an agent have success criteria before it starts?
- A) So it can type faster
- B) So we know how to check whether the task is actually done
- C) So it can avoid using tools
- D) So the app looks more colorful

**Correct:** B

## Question 4

## Question 5

**Q:** In the loop plan -> act -> observe -> test -> refine, what does "observe" mean?
- A) Look at the result of what the AI just changed
- B) Ignore the app and keep prompting
- C) Let the AI do anything
- D) Close the browser

**Correct:** A
