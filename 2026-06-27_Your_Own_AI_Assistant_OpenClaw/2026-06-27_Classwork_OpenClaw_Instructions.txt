------------------------------------------------------------
IMPORTANT SAFETY RULES
------------------------------------------------------------

1. NEVER share the OpenRouter API key in a public chat.
   Treat it like a password.

2. If OpenClaw asks to run a command, READ it first.
   Only approve it if you understand what it is doing.

3. If you are unsure, choose deny and ask the teacher.

4. Work inside a safe test folder only. Do not use folders
   with important files.

5. Keep ask mode on. Do not switch to auto mode.


------------------------------------------------------------
PART 1 - SETUP CHECKPOINT (15 points)
------------------------------------------------------------

Complete these steps with your group.

1. Check Node.js:

   node --version

2. Check OpenClaw:

   openclaw --version

3. Run onboarding if you have not already done it:

   openclaw onboard

   Choose:
   - Provider: OpenRouter
   - API key: use the private class key from your teacher
   - Messaging channel: Skip for now

4. Set the class model:

   openclaw models set openrouter/deepseek/deepseek-v4-flash

5. Confirm the model/account:

   openclaw models status

Answer these questions in your classwork submission:

1. What Node.js version did your computer show?
2. What OpenClaw version did your computer show?
3. Why should the API key be kept private?


------------------------------------------------------------
PART 2 - START OPENCLAW (10 points)
------------------------------------------------------------

You need TWO terminal windows.

TERMINAL 1 - Start the Gateway:

   openclaw gateway

Leave this terminal open. The Gateway is the assistant's
running brain.

TERMINAL 2 - Start chat:

   openclaw chat

When chat opens, type:

   Hello! Introduce yourself in two sentences.

Answer these questions in your classwork submission:

PART 4 - MISSION B: WATCH IT ACT (15 points)
------------------------------------------------------------

First, make a safe test folder.

On Mac:

   mkdir ~/Desktop/openclaw-test
   cd ~/Desktop/openclaw-test

On Windows PowerShell:

   mkdir $env:USERPROFILE\Desktop\openclaw-test
   cd $env:USERPROFILE\Desktop\openclaw-test

Start chat from inside that folder:

   openclaw chat

Ask your assistant:

   Make a file called space.txt with one cool fact about space.

When OpenClaw asks for approval:

1. Read the command carefully.
2. If it looks safe, approve it.
3. If you are unsure, deny it and ask the teacher.

After it finishes, check the file.

On Mac:

   cat space.txt

On Windows PowerShell:

   type space.txt

Answer in your classwork submission:

7. What did OpenClaw want to do before you approved it?
8. What was written inside space.txt?
9. Why is it important that OpenClaw asks before changing files?
