# Kahoot: VS Code, TypeScript Setup, and Decisions

**Date:** August 1, 2026  
**Questions:** 15  
**Suggested time:** 20 seconds per question

Q: Which tool do we use to write and save our code?
A) Node.js
B) Visual Studio Code
C) npm
D) TypeScript Playground only
Correct: B

Q: What is Node.js doing in today's workflow?
A) Drawing the slide deck
B) Installing Windows
C) Running the JavaScript file
D) Replacing VS Code
Correct: C

Q: What does the `tsc` command do?
A) Checks and compiles TypeScript
B) Opens Microsoft Teams
C) Deletes JavaScript
D) Changes the computer password
Correct: A

Q: What does a global TypeScript installation mean for our class?
A) Only one file can use it
B) It works only in the Playground
C) It must be installed every Saturday
D) The `tsc` command can be used in future folders
Correct: D

Q: Which command checks whether Node.js is installed?
A) node --version
B) tsc --version
C) code --version
D) run node
Correct: A

Q: Which file should a student edit?
A) decisions.exe
B) decisions.zip
C) decisions.ts
D) decisions.png
Correct: C

Q: What file is created after compiling `decisions.ts`?
A) decisions.js
B) decisions.pdf
C) decisions.pptx
D) decisions.node
Correct: A

Q: Which order is correct?
A) Run JavaScript, save TypeScript, then compile
B) Compile, delete the file, then write code
C) Save TypeScript, compile it, then run JavaScript
D) Run Node, install VS Code, then save
Correct: C

Q: When does the code inside an `if` branch run?
A) When its condition is true
B) Every time, even when false
C) Only after the final `else`
D) Only in the browser
Correct: A

Q: When is an `else if` condition checked?
A) Before the first `if`
B) After an earlier condition was false
C) Only when every condition is true
D) After the program closes
Correct: B

Q: What is the job of the final `else`?
A) Repeat the first branch
B) Install TypeScript
C) Run when no earlier condition was true
D) Compare two numbers
Correct: C

Q: How many branches run in one `if / else if / else` ladder?
A) Every branch
B) Exactly one branch
C) No branches
D) Always two branches
Correct: B

Q: Why should score conditions usually go from highest to lowest?
A) The first true branch wins
B) Node requires alphabetical order
C) TypeScript cannot read small numbers
D) It makes the file download faster
Correct: A

Q: An AI-written program compiles and runs. What should a human do next?
A) Trust it immediately
B) Delete every condition
C) Test several values and verify the logic
D) Submit it without reading
Correct: C

Q: When should you trust a VS Code workspace?
A) Whenever a stranger sends it
B) When you created the folder or verified its source
C) Every time VS Code asks
D) Only after disabling security
